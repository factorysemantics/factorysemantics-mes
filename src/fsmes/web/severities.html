A new word

The code is what is stored on every non-conformance and printed on a certificate: two to twenty characters, lowercase, starting with a letter. The name is what a person reads beside the record, and the description is the sentence that tells two severities apart. Typing a code that already exists drafts its next revision; typing one that has a draft open edits that draft.

The plant's severities —

A draft is on nobody's screen but this one and the Waiting for you panel on the Floor screen, where somebody holding quality.approve signs it. Retiring changes what may be graded next and never what was graded before: the non-conformances a retired word graded keep it, and so does the certificate that printed it.
