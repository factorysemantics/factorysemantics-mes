A new word

The code is what the analysis groups on and what leaves this plant: two to forty characters, lowercase, starting with a letter. The name is what the operator reads on the button, and the description is the sentence shown beside it at the machine. Typing a code that already exists drafts its next revision; typing one that has a draft open edits that draft.
