What this screen promises

The trace records what the panel showed the person and one sentence per tool call. It never holds the system prompt, never the key, and never a tool's raw payload — a record of the plant's own rows read through this screen would be a way around the capabilities those rows are behind.

A plant in shadow mode writes these rows like any other: the trace changes nothing in the plant and carries nothing off the box. What shadow mode withholds is the cloud brain itself, so a shadow plant's rows are the local model's.

How far a person got through a walkthrough is not recorded. The walk runs in their browser and the plant is not told, and an unknown is written as an unknown rather than guessed at.

My agent

Everything this plant's analysis could say about you, shown to you. That is decision 0039 clause 4, and the test it sets for any analysis this product ever runs: if the plant would not show it to the person it is about, it should not be run. Nothing here is about anybody else, and there is no way to ask this screen about anybody else.
