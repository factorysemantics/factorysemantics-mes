# Releases

*Reference. One page per release: what it does, what it does not, and what is
simulated. The GitHub Release body is taken from the page.*

The full record of every change is in
[CHANGELOG.md](https://github.com/factorysemantics/factorysemantics-mes/blob/main/CHANGELOG.md),
and its **Honesty** section is the one to read before upgrading a plant
anyone reads numbers off. These pages are the summary a person reads first.

| Version | Date | What it is |
|---|---|---|
| [0.4.1](0.4.1.md) | 2026-10-23 | an evening on a Windows PC that goes cleanly: a stop that waits until its own ports are free so the next start works, `stop --force` answered in a sentence instead of refused, and three pages that say how to tell which Python owns the `fsmes` you type |
| [0.4.0](0.4.0.md) | 2026-10-16 | a plant on two boxes keeps counting when one of them dies: two nodes against one PostgreSQL with the jobs that must run once held by a lease, a `docker compose` demo with a kill test anyone can run, and screens that say which box holds what |
| [0.3.1](0.3.1.md) | 2026-10-15 | the first run on a Windows PC recovers itself; a simulated plant shaped like your own, three commands from a pip install; one folder of pages any AI assistant can walk you through; and `fsmes doctor`, one file to paste when something is wrong |
| [0.3.0](0.3.0.md) | 2026-10-12 | the bottling plant from `pipx install`, on Linux and Windows; the SPC tab and three things on the floor screens you can click; a chat that explains the chart; maintenance that reaches the right trade |
| [0.2.0](0.2.0.md) | 2026-09-17 | the ERP connector proven against a real ERPNext, everything a first plant needs to run in shadow mode, and plant packs with a fleet console |
| 0.1.2 | 2026-09-08 | the first public releases: `fsmes demo` runs from a PyPI install |

0.1.0, 0.1.1 and 0.1.2 all reached PyPI on the evening of 2026-09-08 and
have no page of their own; the changelog carries them.
