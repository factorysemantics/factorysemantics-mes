# 0.5.0

*Reference. What this release does, what it does not, and what is simulated.*

> **Not yet tagged.** This page is written before the tag so that the release
> body is reviewed rather than typed on release night. The date below is
> filled in when the maintainer tags it.

**Coming from 0.4.2? Five things on the screens are different:**

1. **The Floor** can sort its machines lowest OEE first (the new **Sort** box). A machine with no OEE yet goes last; it is not counted as zero.
2. **Export xlsx** is on every list you would take to Excel: orders, quality checks, non-conformances, maintenance, the audit trail, lots, OEE and downtime.
3. **The Quality page** has **Raise non-conformance** for something seen by eye, with no measurement needed. **Close** now says "closed".
4. **An open order** on the Orders page links to the work instructions for what it makes.
5. **The Floor's quality check** can say which machine it was taken on.

**After the upgrade, start it** (`fsmes demo bottling`): the first start
backs up the database, brings it up to date and says so in one line. For a
plant of your own: `fsmes init-db --pack packs/yourplant`, or `--plant
yourplant` in a fleet.

**Released:** *on tagging.* **Previous:** 0.4.2, on PyPI 2026-10-26.

## What else is new, for a plant person who reads further

**A machine with two tools, or with no state word.** The tag map can count
one machine on several tags and read "down" from a downtime code alone,
named in the plant's words: `Tool A crash (FaultCode 41)`.

**A draft tag map from a Kepware export.** `fsmes tagmap from-kepware`
reads a KEPServerEX project saved as JSON: one machine per device, why it
guessed each tag, every tag it could not place. It talks to no server.
[The page](../operate/kepware-export.md).

**`fsmes scenario`** plays a product through a line by writing timed values
into an OPC UA server. It refuses any tag not on a simulator or memory
channel, has no override flag, and shadow mode refuses it.
[The page](../operate/scenarios.md).

**The 3D line view** fits the whole line on the screen, on a phone too. It
can draw a machine from your pack's own model files. `fsmes layout
from-freecad` puts each machine where your drawing has it.

**The cutlery plant ships**: `fsmes demo cutlery` brings up the lab's 83-machine plant, at a hundredth of the customer's rate, on SQLite, with no checkout.

**`fsmes walk`** has a pretend supervisor, operator or engineer walk a lab
plant in a browser. Each task leaves a one-minute card: done, or stuck and
where. Most of the screen changes above began as one of those cards. It needs a
checkout and a Claude Code login; a plant PC never needs it.

## What 0.5.0 is not

- **Nothing talks to a real tag server yet.** Neither the Kepware draft nor
  `fsmes scenario` has had a real KEPServerEX on the other end. No real plant
  has run any of this, as with every release before it.
- **The AI tab needs a key** (`ANTHROPIC_API_KEY`). Its library moved up a
  major version in this release (1.15 to 2.6).
- **The body-shop and Satisfactory plants are in the repository, not in
  the package.** `pip install` ships the bottling, machining and cutlery
  plants (`fsmes demo bottling`). The others need a checkout.
- **Everything in a lab is simulated**: the line simulator in
  `src/fsmes/sim/`, replayed over OPC UA, or (Satisfactory) a video game,
  which every one of its screens says.
